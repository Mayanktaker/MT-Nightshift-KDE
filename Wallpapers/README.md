# Wallpapers

Abstract, text-free desktop backgrounds generated for this theme set. None of
the images contains a logo, UI mockup, text, or people.

Every variant includes dedicated 16:9 Full HD (1920x1080), 32:9 Panoramic
Dual-FHD (3840x1080), 32:9 Panoramic Dual-QHD (5120x1440), and 16:9 4K UHD
(3840x2160) wallpapers rendered from lossless master compositions matching each
theme's exact palette blocks.

## Generation Prompts

Two master prompts were used, with the palette swapped per look.

**Dark master (Nightshift / Nord Night / One Dark Pro):**

> Create a minimal abstract desktop wallpaper: wide, calm, matte layers of
> overlapping geometric ridges or paper-cut facets, generously spaced, with a
> large quiet centre area so desktop icons and windows stay legible. Flat opaque
> surfaces, clean deliberate edges, subtle low-contrast depth, no pure black
> and no white. Palette: dominant [DOMINANT], deep [DEEP], mid [MID]; accent
> [ACCENT] used sparingly in under 5% of the image as a thin line or small
> facet; highlight [HIGHLIGHT] only as a faint trace. Mood: precise, calm,
> modern, restrained. Avoid neon, glow, glass, blur, glossy 3D, lens flare,
> grain, text, logos, and UI mockups. Produce a 16:9 composition with the
> focal structure off-centre, plus a wide 32:9 panoramic variant using the
> same palette.

**Light master (Dayshift / Nord Day):**

> Create a minimal abstract desktop wallpaper: wide, calm, matte layers of
> overlapping geometric ridges or soft faceted paper shapes, bright and airy
> with a large quiet centre area so desktop icons and windows stay legible.
> Flat opaque surfaces, clean deliberate edges, subtle low-contrast depth,
> no pure white and no black. Palette: dominant [DOMINANT], lightest [LIGHT],
> mid [MID]; accent [ACCENT] used sparingly in under 5% of the image as a thin
> line or small facet; highlight [HIGHLIGHT] only as a faint trace. Mood:
> crisp, quiet, cool, restrained. Avoid neon, glow, glass, blur, glossy 3D,
> lens flare, grain, text, logos, and UI mockups. Produce a 16:9 composition
> with the focal structure off-centre, plus a wide 32:9 panoramic variant
> using the same palette.

## Tooling & Verification

The suite is managed via `tools/wallpapers/build-wallpapers.py`:
- `make wallpapers`: rebuilds all 20 wallpaper files from `Wallpapers/sources/`
- `./tools/wallpapers/build-wallpapers.py --check`: validates presence and dimensions of all wallpapers
- `make check`: runs the wallpaper verification alongside all theme and style checks

## Using a Wallpaper

Global Themes in this repository deliberately omit wallpaper defaults so they
never overwrite a user's choice. Set a wallpaper through System Settings, or
with `plasma-apply-wallpaperimage <file>` when testing.
